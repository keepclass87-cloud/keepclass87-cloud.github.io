# KUROFRAME — Digital Folklore Archive

Одностраничный сайт-архив. Статика без сборщика: обычные HTML, CSS и JS.

Собран по дизайн-системе **KUROFRAME** из Claude Design
(`ui_kits/kuroframe-site`, handoff-архив).

---

## Запуск

```bash
python -m http.server 8000
```

Открыть http://localhost:8000

Двойной клик по `index.html` тоже сработает — внешних запросов к JSON нет,
данные лежат в обычном `.js`-файле.

---

## Что изменено по сравнению с исходным ui-китом

Исходник — React 18 + Babel Standalone, подключённые с unpkg, с компиляцией
JSX прямо в браузере. Для макета это нормально, для боевого сайта нет: около
3 МБ рантайма и разбор JSX на каждой загрузке.

**Порт в статику.** React убран целиком, компоненты перенесены в CSS-классы,
интерактив — в `assets/js/app.js` (около 260 строк, без зависимостей).
Внешних скриптов не осталось; из сети грузятся только шрифты Google.

**Токены не тронуты.** `assets/css/tokens/*` скопированы из handoff как есть и
остаются контрактом дизайн-системы. Всё, что раньше жило в inline-стилях
компонентов, вынесено в `assets/css/site.css`.

**Иконки вшиты.** `Icon.jsx` грузил SVG с unpkg как `<img>` и перекрашивал их
CSS-фильтрами. Четыре нужные иконки Lucide вставлены инлайном и красятся через
`currentColor` — минус внешняя зависимость и хак с фильтрами.

**Про неиспользованные картинки.** В handoff лежали три файла, не подключённые
ни к одному экрану: `keeper-figure.png`, `hero-keeper.png`, `ritual-process.png`.
README ui-кита описывал их как часть композиции hero и Process, но по решению
заказчика оба экрана несут только типографику. Все три файла удалены.

**Дописан адаптив.** В исходной записи мобильной раскладки не было, в ui-ките
она помечена как пропуск. Правила в конце `site.css` не дают сайту развалиться
на узких экранах: круговая карта частот раскладывается сеткой, селектор и
метаполоса перестраиваются, навигация прячет ссылки.

## Структура

```
index.html                  вся разметка: пять экранов + окно записи
assets/css/
  tokens/                   дизайн-система из handoff, править осторожно
    fonts.css               Archivo + Noto Sans JP
    colors.css              void / bone / signal — два фона, один акцент
    typography.css          display, editorial, labels, numerals
    spacing.css             шаг 4px, полосы секций 96–160px
    effects.css             радиусы, свечения, тайминги
    base.css                сброс, ссылки, фокус, зерно
  site.css                  компоненты и экраны
assets/js/
  data.js                   пять стражей и навигация
  app.js                    выбор стража, карта частот, окно записи, scroll spy
assets/img/                 стражи, портреты, логотип
```

---

## Как менять контент

Стражи и их данные — в [`assets/js/data.js`](assets/js/data.js). Порядок в
массиве задаёт порядок в селекторе и на карте частот. Поля: `index`, `name`,
`archetype`, `frequency`, `src`, `note`.

Карта частот рассчитана на **пять** записей: десять слотов на окружности,
записи занимают каждый второй. Другое число стражей потребует правки
констант `SLOTS` и `RADIUS_PCT` в `app.js`.

Тексты экранов (манифест, шаги ритуала, показатели) лежат прямо в `index.html`.

---

## Шрифты

В `tokens/fonts.css` стоит пометка от автора системы: оригинал набран
лицензионным неогротеском (класс Helvetica Now Display / Neue Haas Grotesk),
бинарников в handoff нет, поэтому подставлен ближайший свободный — **Archivo**.
Когда появятся настоящие файлы, заменить `@import` на локальные `@font-face`.

## Публикация на GitHub Pages

```bash
git add -A
git commit -m "KUROFRAME"
git branch -M main
git remote add origin https://github.com/ПОЛЬЗОВАТЕЛЬ/РЕПОЗИТОРИЙ.git
git push -u origin main
```

Затем **Settings → Pages → Source: Deploy from a branch → main / (root)**.

`.nojekyll` в корне уже лежит. Вес сайта — около 2 МБ, почти всё картинки.
