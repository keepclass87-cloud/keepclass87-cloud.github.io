# tepsuevvv — портфолио

Статический сайт: печатный дизайн, 2D- и 3D-анимационные ролики.
Без сборщиков и зависимостей — обычные HTML, CSS и JS-модули.

---

## Локальный запуск

```bash
python -m http.server 8000
```

Открыть http://localhost:8000

Через двойной клик по `index.html` сайт **не заработает**: по протоколу `file://`
браузер запрещает читать JSON, и галерея останется пустой. Это ожидаемо.

## Рендер телевизора в Blender

Телевизор на первом экране — не картинка, а поворачивающийся за курсором объект.
Собирается из секвенции кадров, отрендеренных в Blender.

### Сцена

- **Камера ставится один раз и больше не двигается** — ни между кадрами, ни между
  пассами. Вращается телевизор, а не камера, иначе слои не совпадут.
- Телевизор родительствуется к Empty в центре основания.
- Ключи на Empty по **оси Z** (мировая вертикаль в Blender):
  кадр 1 = `−18°`, кадр 25 = `+18°`.
- Выделить оба ключа → `T` → **Linear**. С Bezier шаг между кадрами будет
  неравномерным и поворот «залипнет» по краям диапазона.
- Кадрировать с запасом ~12% по краям, чтобы на крайних углах ничего не срезало.

### Настройки вывода

| Параметр | Значение |
|---|---|
| `Render → Film → Transparent` | включено |
| Формат | PNG, RGBA, 8-bit |
| Разрешение | 1800×1350, **одинаково для всех пассов** |
| Color Management | один и тот же во всех пассах |

### Пассы

Каждый — отдельный рендер с той же камерой, в папку `_source/`:

| Куда | Что в кадре | Кадров |
|---|---|---|
| `_source/tv/` | телевизор и тумба, экран выключен (чёрный) | 25 |
| `_source/screen/` | **только плоскость экрана**, белый Emission, остальное скрыто | 25 |
| `_source/bg.png` | комната и фон, без телевизора | 1 |
| `_source/glow.png` | засветка от экрана на окружение | 1 |
| `_source/props.png` | передний план: кружка, мелочи | 1 |
| `_source/smoke-far.png` | дальняя дымка | 1 |
| `_source/smoke-near.png` | ближняя дымка | 1 |

Маска экрана обязательна. По ней вычисляются координаты четырёх углов экрана на
каждом кадре, и в это место вписывается живой HTML-элемент — с анимацией
включения и превью работ при наведении на карточку. Без маски экран пришлось бы
запечь в картинку, и он стал бы мёртвым.

### Приёмка рендеров

```bash
python tools/prepare_hero.py
```

Скрипт переганяет PNG в WebP двух размеров (десктоп и мобильный), считает углы
экрана по маскам и складывает всё в `assets/img/hero/` вместе с манифестом
`hero.json`. В конце печатает отчёт по весу.

Папка `_source/` закрыта в `.gitignore` — исходные PNG на сотни мегабайт в
репозиторий не попадают.

## Добавить работу

1. Положить файлы:
   - изображения → `assets/img/works/`
   - видео → `assets/video/`
2. Дописать объект в массив `works` в [`content/works.json`](content/works.json).

Код править не нужно. Порядок в массиве = порядок на сайте.
В конце файла, в блоке `_examples`, лежат готовые шаблоны для копирования —
сайтом этот блок не читается.

Поле `media` понимает три типа:

| Тип | Для чего |
|---|---|
| `image` | картинка |
| `video` | локальный MP4 |
| `embed` | ролик с YouTube или Vimeo по id |

### Видео: важные ограничения GitHub Pages

- **100 МБ на файл** — жёсткий лимит, push с файлом больше просто отклонится.
- Размер сайта — до **1 ГБ**, трафик ~100 ГБ в месяц.
- **Git LFS использовать нельзя**: Pages отдаёт вместо видео текстовый
  pointer-файл, и ролик не проиграется.

Поэтому: длинные ролики заливать на YouTube и подключать через `embed`,
локально держать только короткие лупы и тизеры. Ориентир для локальных —
H.264, 1080p, 2–4 Мбит/с, то есть примерно 15–30 МБ на минуту.

Постер-кадр для каждого видео обязателен: в сетке грузится только он, само
видео создаётся лишь в момент открытия лайтбокса.

## Тексты и контакты

Всё в [`content/site.json`](content/site.json).

- `shared.contacts` — почта, Telegram, Behance. **Заполнить своими** — сейчас там
  заглушки.
- `shared.tools` — список инструментов в разделе «Обо мне».
- `marquee` — слова в бегущей строке под первым экраном. Порядок важен: через
  одно слово идёт контурным начертанием.
- `statement` — крупная фраза, слова которой загораются по мере прокрутки.
  Разбивается на слова автоматически, просто напишите текст одной строкой.
- `ru` и `en` — тексты интерфейса. Структура блоков должна совпадать: массивы
  `services.items` и `process.steps` сопоставляются по порядку.

Русский текст в `index.html` — рабочий запасной вариант: если ключа нет в JSON,
элемент останется с ним. Ничего не сломается и не опустеет.

## Публикация на GitHub Pages

```bash
git add -A
git commit -m "Портфолио"
git branch -M main
git remote add origin https://github.com/ПОЛЬЗОВАТЕЛЬ/РЕПОЗИТОРИЙ.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Source: Deploy from a branch →
main / (root)**.

Файл `.nojekyll` в корне уже лежит — без него Pages игнорирует файлы и папки,
начинающиеся с подчёркивания.

## Структура

```
index.html              единственная страница, секции-якоря
assets/css/
  tokens.css            палитра, шрифты, ритм, глубина — вся правка цвета тут
  base.css              сброс, типографика, зерно, появление блоков
  layout.css            шапка, навигация, сетка секций, кнопки
  scenes.css            hero-сцена, телевизор, CRT, лента, заявление, галерея
assets/js/
  main.js               загрузка контента, связывание модулей, scroll spy
  parallax.js           движок глубины: один rAF-цикл на всю сцену
  motion.js             бегущая строка и загорающееся заявление
  tv.js                 экран телевизора: включение и «каналы»
  i18n.js               переключение RU/EN
  gallery.js            работы, фильтры, услуги, этапы, контакты
  lightbox.js           просмотр работы, ленивое видео, клавиатура
content/
  site.json             тексты интерфейса и контакты
  works.json            список работ
tools/
  prepare_hero.py       приёмка рендеров из Blender
```
